# Alabaster Dawn visual references

The five screenshots supplied by Simon are saved here in their original uploaded form:

1. `01-environment.png` — full scene, camera perspective and character scale.
2. `02-character-front.png` — front view.
3. `03-character-side.png` — side view.
4. `04-character-back.png` — back view.
5. `05-character-opposite-side.png` — opposite side view.

`06-character-four-directions-reference.png` is a labeled front/right/back/left reference sheet assembled from the four character screenshots using built-in image generation. Use the original screenshots above when exact source pixels matter.

Use these for proportions, camera angle, and pixel-detail reference. They are screenshots, so their displayed dimensions do not establish the game's native sprite dimensions.
