# Concept 08: eight direction references

Eight generated pixel-art reference images based on the supplied blonde heroine concept. These are larger design references for later sprite drawing.

Open `index.html` for the labeled gallery, or use the individual transparent PNG files:

- `concept-08-up.png`: Up / back
- `concept-08-up-right.png`: Up-right / rear diagonal
- `concept-08-right.png`: Right / profile
- `concept-08-down-right.png`: Down-right / front diagonal
- `concept-08-down.png`: Down / front
- `concept-08-down-left.png`: Down-left / front diagonal
- `concept-08-left.png`: Left / profile
- `concept-08-up-left.png`: Up-left / rear diagonal

Directions describe character-facing direction on screen. The four diagonal views sit between the cardinal views. Each image was generated separately with the original concept and a shared front-facing anchor. Use the source and front anchor to resolve small generated design variations when drawing the final sprite.

`generation-prompts.md` records the complete prompt set and generation mode. `source-concept.png` preserves the supplied reference. `concept-08-eight-direction-references.zip` packages the eight PNGs, README, and prompts.
